# 一、Hbuilder实现git关联

- 为何需要使用 easy-git 来实现，原本的Hbuilder 提供的git 需要安装 tortoisegit 我用不习惯  



### 1、在插件市场安装 easy-git 

链接：[easy-git （Hbuilder插件市场）](https://ext.dcloud.net.cn/plugin?id=2475 )

### 2、在Hbuilder 找到 工具 -> Git源代码管理 

-  选中Git源代码管理 ，左下角就会出现 git 图标，选中就可以git命令提交了

![image-20250731103245717](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250731103245717.png)



### 3、安装git

- 安装uniapp自带的git目的是为了修改代码能够看到有提示，方便开发和维护。
