# 3. `git` 代码复制到另外一个仓库

## 代码示例

> ```shell
> // 所有的操作都是在原先的仓库进行操作，前提条件就是（已经创建好了目标远程，并且自己有权限推送代码）
> // 3DWORK: 目标远程仓库名
> // https://gitee.com/juan951219520/3Dwork.git :目标远程仓库地址
> // huayang-center-1.4 :原先的仓库地址分支

> 
> git push 3DWORK huayang-center-1.4
> 
> `然后自己拉取目标仓库地址的代码`
> ```

# 5.内网穿透

## 代码示例

> ```shell
> 外网访问内网项目，查看本地项目
> 
> 使用方式 Localtunnel
> 
> 端口号：就是项目本地跑动代码的端口号
> 
> 如果没有全局安装过 ，执行此命令
> npx localtunnel --port 端口号 (bash执行)
> 
> 全局安装命令
> npm install -g localtunnel
> 
> //如果全局安装了
> lt --port 端口号 (bash)
> 
> 执行完这条命令会返回一个地址给你，这个网址是动态分配的。在浏览器打开这个地址。
> your url is: `https://brown-jokes-change.loca.lt`
> 
> 此时需要你输入一个密码，这个密码就是你的IP地址。(点击文中这个链接 `https://loca.lt/mytunnelpassword` 就能获取到你的ip)
> 
> 然后就能分享给别人查看，`本地断开连接就能关闭`。
> 
> 
> 
> ```

# 7.`vue3`下拉菜单鼠标悬停的时候出现黑色边框

## 代码实例

> ```vue
> <template>
> <el-dropdown
>  trigger="click"
>  class="custom-dropdown"
>   >
>  <el-button>
>    下拉菜单 <i class="el-icon-arrow-down el-icon--right"></i>
>  </el-button>
>  <el-dropdown-menu slot="dropdown">
>    <el-dropdown-item>选项1</el-dropdown-item>
>    <el-dropdown-item>选项2</el-dropdown-item>
>    <el-dropdown-item>选项3</el-dropdown-item>
>  </el-dropdown-menu>
> </el-dropdown>
> </template>
> 
> <script>
> export default {
> name: 'MyDropdown'
> };
> </script>
> 
> <style>
>    // 如过样式不生效，就加deep  
> .custom-dropdown .el-dropdown-menu {
> border: 2px solid black; /* 黑色边框 */
> box-shadow: none; /* 如果需要可以移除阴影 */
> }
> 
> .custom-dropdown .el-dropdown-menu:focus {
> outline: none; /* 移除焦点时的轮廓 */
> }
> 
> /* 可选：在悬停时改变边框颜色 */
> .custom-dropdown .el-dropdown-menu:hover {
> border-color: darkgray; /* 悬停时改变边框颜色 */
> }
> </style>
> 
> ```

# 9.`electron`首页渲染白屏问题

## 解决方式

```js
// 原因： electron 不是history模式的路由 只是支持hash模式
// 在vue3中实现的方式
const router = createRouter({
	// history: createWebHistory(import.meta.env.BASE_URL),
	history: createWebHashHistory(),  //hash模式
	routes
})
```
