# 南充市天地图瓦片下载脚本使用说明

## 1. 功能说明

`download_tianditu_nanchong.py` 用于下载南充市矩形范围内的天地图离线瓦片。

- 坐标系：WGS 84 经纬度范围（EPSG:4326）
- 瓦片规则：Web 墨卡托 XYZ
- 下载级别：6～10级
- 瓦片尺寸：256 × 256像素
- 下载范围：`(105.45, 30.43, 107.02, 31.87)`
- 依赖环境：Python 3.10及以上版本
- 第三方依赖：无，仅使用 Python 标准库

> 注意：当前范围是覆盖南充市的矩形，会包含边缘少量相邻地区，并不是严格按照南充行政区划多边形裁切。

## 2. 下载图层

脚本默认下载以下四个图层：

| 图层编号 | 图层名称 | 文件格式 | 作用 |
| --- | --- | --- | --- |
| `vec_w` | 矢量底图 | PNG | 道路、水系、区域等矢量风格底图 |
| `cva_w` | 矢量中文注记 | PNG | 矢量地图的地名、道路名称等注记 |
| `img_w` | 影像底图 | JPG | 卫星影像底图 |
| `cia_w` | 影像中文注记 | PNG | 影像地图的地名、道路名称等注记 |

中文注记图层通常带有透明背景，需要覆盖在对应底图上使用：

- 矢量地图：`vec_w + cva_w`
- 影像地图：`img_w + cia_w`

## 3. 瓦片数量

南充市当前矩形范围内，每个图层的瓦片数量如下：

| 级别 | 单个图层瓦片数量 |
| ---: | ---: |
| 6 | 2张 |
| 7 | 2张 |
| 8 | 6张 |
| 9 | 12张 |
| 10 | 36张 |
| 合计 | 58张 |

四个图层总计约 **232张瓦片**。

## 4. 配置天地图 TK

打开 `download_tianditu_nanchong.py`，找到以下配置：

```python
TIANDITU_TK = ""
```

在引号内填写自己申请的天地图 TK：

```python
TIANDITU_TK = "请填写你自己的天地图TK"
```

不要把真实 TK 提交到 Git、公开文档或发给无关人员。如果 TK 已经公开，建议前往天地图开发者控制台重新生成。

## 5. 在 VS Code 中运行

### 5.1 打开脚本所在目录

将脚本放入一个单独目录，例如：

```text
C:\Users\Administrator\Desktop\py
```

使用 VS Code 打开该目录，然后点击下方的“终端”。

不要使用 Code Runner 的“输出”窗口，因为脚本需要输入 `y` 进行确认，“输出”窗口无法正常交互。


```powershell
python download_tianditu_nanchong.py --dry-run
```

预览模式不会连接天地图，也不会下载文件。

运行：


出现以下提示时：

## 6. 下载目录结构

脚本会在自身所在目录创建 `tianditu_nanchong` 文件夹：

```text
tianditu_nanchong/
├─ vec_w/
│  ├─ 6/x/y.png
│  ├─ 7/x/y.png
│  ├─ 8/x/y.png
│  ├─ 9/x/y.png
│  └─ 10/x/y.png
├─ cva_w/
│  └─ 级别/x/y.png
├─ img_w/
│  └─ 级别/x/y.jpg
├─ cia_w/
│  └─ 级别/x/y.png
└─ failed_tiles.txt
```

实际路径示例：

```text
tianditu_nanchong/vec_w/10/813/419.png
tianditu_nanchong/img_w/10/813/419.jpg
```

只有存在下载失败时，才会生成 `failed_tiles.txt`。

## 7. 断点续传和失败重试

脚本支持断点续传：

- 已存在且大小正常的瓦片会自动跳过。
- 下载中断后，直接重新运行相同命令即可继续。
- 单张瓦片最多自动重试3次。
- 失败记录会写入 `failed_tiles.txt`。

重新运行：

```powershell
python download_tianditu_nanchong.py
```

不需要删除已经下载的文件。

## 10. XYZ 与 TMS 设置

本脚本下载的是标准 **XYZ瓦片**，没有进行 TMS 的 Y 轴翻转。

因此 Leaflet 中不要配置：

```javascript
tms: true
```

正确配置是省略 `tms`，或者明确写成：

```javascript
tms: false
```

如果错误配置了 `tms: true`，可能出现地图上下错位、瓦片显示到错误位置或者大量瓦片无法找到。

如果使用 QTiles 重新生成同样的瓦片，为了与本脚本和浏览器 Demo 保持一致，应取消勾选：

```text
Enable TMS tile convention
```

## 11. 常见问题

### 11.1 中文显示乱码

请使用 VS Code 的“终端”运行，不要使用 Code Runner 的“输出”窗口。

可以先在 PowerShell 中执行：

```powershell
chcp 65001
```

然后运行脚本：

```powershell
python download_tianditu_nanchong.py
```

### 11.2 提示 TK 无效或没有返回图片

检查以下内容：

1. TK 是否填写完整。
2. TK 是否已经启用。
3. TK 是否存在调用限制或额度限制。
4. 当前电脑是否能够访问天地图服务。
5. 电脑日期和时间是否正确。

### 11.3 下载后地图只有文字，没有底图

可能只加载了注记图层。

- `cva_w` 必须覆盖在 `vec_w` 上。
- `cia_w` 必须覆盖在 `img_w` 上。

### 11.4 影像瓦片无法显示

影像底图使用 `.jpg` 后缀：

```text
img_w/{z}/{x}/{y}.jpg
```

不能写成：

```text
img_w/{z}/{x}/{y}.png
```

### 11.5 地图出现上下错位

检查是否错误设置了：

```javascript
tms: true
```

当前脚本为 XYZ 格式，应删除该配置或改成 `tms: false`。

### 11.6 重新运行时显示“跳过”

这是正常现象，说明该瓦片已经下载完成。脚本会跳过现有文件，避免重复下载。

## 12. 注意事项

1. 请使用自己申请的天地图 TK。
2. 不要将真实 TK 上传到 GitHub 或公开服务器。
3. 下载和使用地图数据时，应遵守天地图服务条款及相关数据许可要求。
4. 建议先运行 `--dry-run` 确认范围和瓦片数量。
5. 不建议盲目提高 `MAX_WORKERS`，避免请求过快导致服务限制。
6. 下载范围为矩形，如需严格按照南充行政边界裁切，需要额外的行政区划边界数据。

## 13. 完整 Python 源码

下面的代码可以完整复制到 `download_tianditu_nanchong.py` 中运行。请先把自己的 TK 填入 `TIANDITU_TK`，不要公开真实 TK。

```python
# -*- coding: utf-8 -*-
"""
下载南充市范围的天地图瓦片（6～10级）。

四个图层：
1. vec_w：矢量底图
2. cva_w：矢量中文注记
3. img_w：影像底图
4. cia_w：影像中文注记

输出目录：
tianditu_nanchong/图层名/级别/x/y.扩展名

仅使用 Python 标准库，无需安装第三方包。
请使用你自己申请的天地图 TK，并遵守天地图服务条款。
"""

from __future__ import annotations

import argparse
import math
import os
import random
import sys
import threading
import time
from concurrent.futures import ThreadPoolExecutor, as_completed
from dataclasses import dataclass
from pathlib import Path
from urllib.error import HTTPError, URLError
from urllib.parse import urlencode
from urllib.request import Request, urlopen


# ======================== 用户配置 ========================

# 可以把申请到的天地图 TK 填在引号内；留空时，运行后会提示输入。
TIANDITU_TK = ""

# 南充市矩形覆盖范围（西、南、东、北），已稍微向外留出余量。
# 如需缩小或扩大下载范围，可修改这里。
NANCHONG_BBOX = (105.45, 30.43, 107.02, 31.87)

MIN_ZOOM = 6
MAX_ZOOM = 10

# 同时下载线程数。建议保持较小，避免给服务端造成过大压力。
MAX_WORKERS = 4

TIMEOUT_SECONDS = 20
MAX_RETRIES = 3

# 下载目录默认创建在本脚本旁边。
OUTPUT_DIR = Path(__file__).resolve().parent / "tianditu_nanchong"

# 图层名:（中文名称，文件扩展名）
LAYERS = {
    "vec_w": ("矢量底图", ".png"),
    "cva_w": ("矢量中文注记", ".png"),
    "img_w": ("影像底图", ".png"),
    "cia_w": ("影像中文注记", ".png"),
}

# =========================================================


PRINT_LOCK = threading.Lock()


@dataclass(frozen=True)
class TileTask:
    layer: str
    zoom: int
    x: int
    y: int
    extension: str


def configure_console() -> None:
    """尽量避免 Windows/Code Runner 中文输出乱码。"""
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except (AttributeError, OSError):
            pass


def lon_to_tile_x(longitude: float, zoom: int) -> int:
    tile_count = 1 << zoom
    x = int((longitude + 180.0) / 360.0 * tile_count)
    return max(0, min(tile_count - 1, x))


def lat_to_tile_y(latitude: float, zoom: int) -> int:
    # Web 墨卡托只支持约 ±85.05112878°。
    latitude = max(-85.05112878, min(85.05112878, latitude))
    latitude_rad = math.radians(latitude)
    tile_count = 1 << zoom
    y = int(
        (1.0 - math.asinh(math.tan(latitude_rad)) / math.pi)
        / 2.0
        * tile_count
    )
    return max(0, min(tile_count - 1, y))


def tile_range_for_bbox(
    bbox: tuple[float, float, float, float], zoom: int
) -> tuple[int, int, int, int]:
    west, south, east, north = bbox
    min_x = lon_to_tile_x(west, zoom)
    max_x = lon_to_tile_x(east, zoom)
    min_y = lat_to_tile_y(north, zoom)
    max_y = lat_to_tile_y(south, zoom)
    return min_x, max_x, min_y, max_y


def build_tasks() -> list[TileTask]:
    tasks: list[TileTask] = []
    for layer, (_, extension) in LAYERS.items():
        for zoom in range(MIN_ZOOM, MAX_ZOOM + 1):
            min_x, max_x, min_y, max_y = tile_range_for_bbox(
                NANCHONG_BBOX, zoom
            )
            for x in range(min_x, max_x + 1):
                for y in range(min_y, max_y + 1):
                    tasks.append(TileTask(layer, zoom, x, y, extension))
    return tasks


def build_url(task: TileTask, token: str) -> str:
    # 天地图提供 t0～t7 多个服务节点。
    server_number = (task.x + task.y + task.zoom) % 8
    query = urlencode(
        {
            "T": task.layer,
            "x": task.x,
            "y": task.y,
            "l": task.zoom,
            "tk": token,
        }
    )
    return f"https://t{server_number}.tianditu.gov.cn/DataServer?{query}"


def tile_path(task: TileTask) -> Path:
    return (
        OUTPUT_DIR
        / task.layer
        / str(task.zoom)
        / str(task.x)
        / f"{task.y}{task.extension}"
    )


def looks_like_image(data: bytes, content_type: str) -> bool:
    if content_type.lower().startswith("image/"):
        return True
    signatures = (
        b"\x89PNG\r\n\x1a\n",
        b"\xff\xd8\xff",
        b"GIF87a",
        b"GIF89a",
        b"RIFF",  # WebP 文件以 RIFF 开头。
    )
    return any(data.startswith(signature) for signature in signatures)


def download_one(task: TileTask, token: str) -> tuple[str, str]:
    destination = tile_path(task)

    # 文件已存在且不为空时直接跳过，实现断点续传。
    if destination.exists() and destination.stat().st_size > 100:
        return "skipped", str(destination)

    destination.parent.mkdir(parents=True, exist_ok=True)
    url = build_url(task, token)
    last_error = "未知错误"

    for attempt in range(1, MAX_RETRIES + 1):
        try:
            request = Request(
                url,
                headers={
                    "User-Agent": (
                        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                        "AppleWebKit/537.36 Chrome/151 Safari/537.36"
                    ),
                    "Accept": "image/avif,image/webp,image/png,image/jpeg,*/*;q=0.8",
                },
            )
            with urlopen(request, timeout=TIMEOUT_SECONDS) as response:
                data = response.read()
                content_type = response.headers.get("Content-Type", "")

            if len(data) <= 100 or not looks_like_image(data, content_type):
                preview = data[:120].decode("utf-8", errors="replace")
                raise ValueError(
                    f"服务端未返回有效图片，可能是 TK 无效或额度受限：{preview!r}"
                )

            temporary = destination.with_suffix(destination.suffix + ".part")
            temporary.write_bytes(data)
            os.replace(temporary, destination)
            return "downloaded", str(destination)

        except (HTTPError, URLError, TimeoutError, OSError, ValueError) as exc:
            last_error = f"{type(exc).__name__}: {exc}"
            if attempt < MAX_RETRIES:
                time.sleep((2 ** (attempt - 1)) + random.random())

    return "failed", (
        f"{task.layer} z={task.zoom} x={task.x} y={task.y} | {last_error}"
    )


def print_plan(tasks: list[TileTask]) -> None:
    print("=" * 64)
    print("天地图南充市瓦片下载任务")
    print("=" * 64)
    print(f"经纬度范围：{NANCHONG_BBOX}")
    print(f"缩放级别：{MIN_ZOOM}～{MAX_ZOOM}")
    print(f"保存位置：{OUTPUT_DIR}")
    print(f"并发线程：{MAX_WORKERS}")
    print("\n各图层瓦片数量：")
    for layer, (name, _) in LAYERS.items():
        count = sum(task.layer == layer for task in tasks)
        print(f"  {layer:<5} {name:<10} {count:>4} 张")
    print(f"\n总计：{len(tasks)} 张")


def parse_arguments() -> argparse.Namespace:
    parser = argparse.ArgumentParser(description="下载南充市天地图瓦片")
    parser.add_argument(
        "--tk",
        default="",
        help="天地图开发者 TK；不传时读取脚本配置或交互输入",
    )
    parser.add_argument(
        "--dry-run",
        action="store_true",
        help="只显示下载范围和瓦片数量，不连接网络",
    )
    return parser.parse_args()


def main() -> int:
    configure_console()
    args = parse_arguments()
    tasks = build_tasks()
    print_plan(tasks)

    if args.dry_run:
        print("\n这是预览模式，未下载任何文件。")
        return 0

    token = args.tk.strip() or TIANDITU_TK.strip()
    if not token:
        try:
            token = input("\n请输入你申请的天地图 TK：").strip()
        except EOFError:
            token = ""

    if not token:
        print("错误：TK 不能为空。请在脚本顶部填写 TIANDITU_TK。")
        return 1

    answer = input("确认开始下载吗？输入 y 后回车：").strip().lower()
    if answer not in {"y", "yes"}:
        print("已取消下载。")
        return 0

    downloaded = 0
    skipped = 0
    failures: list[str] = []
    completed = 0

    print("\n开始下载……")
    with ThreadPoolExecutor(max_workers=MAX_WORKERS) as executor:
        future_map = {
            executor.submit(download_one, task, token): task for task in tasks
        }
        for future in as_completed(future_map):
            status, detail = future.result()
            completed += 1
            if status == "downloaded":
                downloaded += 1
            elif status == "skipped":
                skipped += 1
            else:
                failures.append(detail)

            with PRINT_LOCK:
                print(
                    f"\r进度：{completed}/{len(tasks)} | "
                    f"新下载 {downloaded} | 跳过 {skipped} | "
                    f"失败 {len(failures)}",
                    end="",
                    flush=True,
                )

    print("\n")
    if failures:
        failed_file = OUTPUT_DIR / "failed_tiles.txt"
        failed_file.parent.mkdir(parents=True, exist_ok=True)
        failed_file.write_text("\n".join(failures), encoding="utf-8")
        print(f"有 {len(failures)} 张下载失败，详情已保存到：{failed_file}")
        print("修复网络或 TK 问题后重新运行，程序会自动跳过已下载文件。")
        return 2

    print("全部下载完成！")
    print(f"瓦片目录：{OUTPUT_DIR}")
    print("提示：这些是 XYZ 瓦片，Leaflet 中不要设置 tms: true。")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
